# Issue tracker: GitHub Issues

Issues and specs for this repo live in GitHub Issues.

## Repository

https://github.com/Livzon-DS-Sector-AI-Innovation/Livzon-Syntpharm

## When a skill says "publish to the issue tracker"

Use the `gh` CLI to create a new issue:

```bash
gh issue create --title "Issue title" --body "Issue description"
```

## When a skill says "fetch the relevant ticket"

Use the `gh` CLI to read the issue:

```bash
gh issue view <issue-number>
```

## Triage labels

Issues are labeled with triage state using GitHub labels. See `triage-labels.md` for the label vocabulary.

## PRs as a request surface

Disabled by default. External PRs are not automatically added to the triage queue.
