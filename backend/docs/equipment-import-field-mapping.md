### ⚠️ 特殊处理字段

#### 1. 设备分类
- **前端**: 下拉选择（多选）
- **Excel**: 文本（如"A类"、"B类"、"C类"）
- **后端**: `category_ids` (UUID 列表)
- **处理方式**: 
  - 从 Excel 读取文本（如"A类"）
  - 查询数据库找到对应的分类 ID
  - 如果找不到，跳过该字段

#### 2. 设备位置
- **前端**: 树形选择或文本输入
- **Excel**: 文本（如"微生物室"、"404二楼"）
- **后端**: `location_id` (UUID) 或 `location_text` (文本)
- **处理方式**: 
  - 优先使用 `location_text` 保存文本
  - 如果需要关联位置 ID，需要额外查询

#### 3. 设备状态
- **前端**: 下拉选择（在用/备用/维修中/停用/报废）
- **Excel**: 通常不填
- **后端**: `status` (默认"在用")
- **处理方式**: 默认为"在用"

### ❌ 不支持的字段

| Excel 列名 | 原因 | 建议 |
|-----------|------|------|
| 数量 | 后端 EquipmentCreate 没有 quantity 字段 | 忽略该列，或存入 technical_params |
| 设备分类等级 | 前端是下拉选择，Excel 中是文本 | 通过 category_description 或 equipment_class 处理 |

## 🔧 导入时的数据处理流程

```
1. 读取 Excel 行数据
   ↓
2. 使用 COLUMN_MAPPING 提取字段值
   ↓
3. 数据转换：
   - 日期格式转换（2026/6/23 → 2026-06-23）
   - 部门名称映射（环保中心 → 安全环保部）
   - 状态映射（未报废 → scrap_status=None）
   ↓
4. 数据验证：
   - 必填字段检查（资产编号、设备名称）
   - 部门存在性检查
   - 日期格式验证
   ↓
5. 创建或更新设备记录
   ↓
6. 返回导入结果（成功/跳过/错误）
```

## 📝 Excel 模板建议列顺序

为了与前端表单保持一致，建议 Excel 模板按以下顺序排列：

1. 资产编号 *（必填）
2. 设备名称 *（必填）
3. 标签号
4. 设备位号
5. 设备分类（A/B/C）
6. 资产类别说明
7. 设备位置
8. 归属部门 *（必填，需系统中存在）
9. 负责人
10. 设备型号
11. 设备规格
12. 制造商
13. 供应商
14. 出厂日期（YYYY-MM-DD）
15. 投用日期（YYYY-MM-DD）
16. 当前成本
17. 账面净值
18. 报废状态（在用/报废）
19. 报废时间（YYYY-MM-DD）
20. 设备描述

*注：带 * 的为必填字段*

## 🎯 最佳实践

1. **部门名称**：使用标准名称（如"安全环保部"），或使用已配置的别名（如"环保中心"）
2. **日期格式**：统一使用 `YYYY-MM-DD` 或 `YYYY/MM/DD`
3. **数值格式**：不要包含货币符号（¥），直接写数字
4. **空值处理**：可选字段留空即可，不要填"无"或"N/A"
5. **重复检查**：资产编号必须唯一，重复会被跳过

## 🔍 常见问题

### Q1: 部门不存在怎么办？
A: 系统会先尝试精确匹配 DEPT_MAPPING，然后使用模糊匹配（相似度≥80%）。如果都失败，该行会被跳过并记录错误。

### Q2: 日期格式不支持怎么办？
A: 支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY年MM月DD日` 以及 Excel 日期序列号。

### Q3: 如何查看导入错误？
A: 导入完成后会返回详细的错误列表，包括行号和错误原因。

### Q4: 可以部分导入吗？
A: 可以。系统采用"部分成功"模式，成功的记录会保存，失败的记录会跳过并记录错误。
