## 🔗 与导入功能的关联

### 部门映射关系
Excel 中的部门名称会通过 `DEPT_MAPPING` 自动映射到标准部门：

| Excel 名称 | 标准部门 |
|-----------|---------|
| 环保中心 | 安全环保部 |
| 安全中心 | 安全环保部 |
| 检验室 | 质量控制部 |
| 质量部 | 质量保证部 |
| 仪表电工班 | 设备工程部 |
| 仓库 | 仓储部 |
| 炊事班 | 人事行政部 |
| 头孢合成一车间 | 201车间 |
| 头孢合成二车间 | 202车间 |
| ... | ... |

### 模糊匹配
对于未在映射表中的部门名称，系统会使用模糊匹配算法（相似度 ≥ 80%）尝试匹配。
