# 灵活导入指南 - 处理不同格式的 Excel 表格

## 🎯 设计理念

系统采用**智能列名识别 + 灵活映射**策略，能够自动适应各种格式的 Excel 表格。

## ✅ 已实现的功能

### 1. 增强的 COLUMN_MAPPING（后端）

支持 **100+ 种列名别名**，覆盖常见变体：

| 标准字段 | 支持的别名示例 |
|---------|--------------|
| 资产编号 | 编号、资产号、Asset No、设备编号、Equipment No |
| 设备名称 | 资产说明、名称、Name、设备名、Item Name |
| 制造商 | 厂家、Manufacturer、生产商、品牌、Brand |
| 当前成本 | 成本、金额、价值、原值、单价、Purchase Price |
| 部门 | 使用部门、所属部门、归属部门、Dept、Unit |
| ... | ... |

### 2. 数据转换脚本（预处理工具）

**位置**: `backend/scripts/import/convert_excel_to_template.py`

**功能**:
- ✅ 自动识别列名（支持多种别名）
- ✅ 重命列为标准格式
- ✅ 删除不需要的列（如"数量"）
- ✅ 添加缺失的列
- ✅ 统一日期格式（YYYY-MM-DD）
- ✅ 映射部门名称（环保中心 → 安全环保部）

**使用方法**:
```bash
cd $(pwd)/backend
python scripts/import/convert_excel_to_template.py \
    ~/Desktop/202606sbgz.xls \
    ~/Desktop/converted_template.xlsx
```

### 3. 模糊匹配（容错机制）

- **部门名称**: 80% 相似度自动匹配
- **列名识别**: 大小写不敏感，支持中英文混合

## 📋 使用流程

### 方案 A：直接上传（推荐用于格式接近的表格）

如果用户的 Excel 表格列名与系统支持的别名匹配：

1. 用户直接上传 Excel 文件
2. 后端自动识别列名
3. 预览数据
4. 确认导入

**适用场景**:
- 列名基本匹配（如"设备名称"、"制造商"等）
- 部门名称在 DEPT_MAPPING 中
- 日期格式为标准格式

### 方案 B：先转换再上传（推荐用于格式差异大的表格）

如果用户的 Excel 表格格式差异较大：

1. 运行转换脚本预处理
   ```bash
   python scripts/import/convert_excel_to_template.py input.xls output.xlsx
   ```
2. 检查转换后的文件
3. 上传转换后的文件
4. 预览并导入

**适用场景**:
- 列名完全不匹配
- 有大量多余列
- 日期格式混乱
- 需要批量处理多个文件

## 🔧 扩展性设计

### 添加新的列名别名

编辑 `backend/app/modules/equipment/api/batch_import.py`:

```python
COLUMN_MAPPING = {
    "资产编号": [
        "资产编号", "编号", 
        "新增别名1", "新增别名2",  # ← 在这里添加
        ...
    ],
    ...
}
```

### 添加新的部门映射

编辑同一文件中的 `DEPT_MAPPING`:

```python
DEPT_MAPPING = {
    "新部门别名": "标准部门名称",  # ← 在这里添加
    ...
}
```

### 自定义转换规则

编辑 `backend/scripts/import/convert_excel_to_template.py`:

```python
# 添加新的列名映射
COLUMN_NAME_MAPPING["新字段"] = ["别名1", "别名2"]

# 添加新的部门映射
DEPT_MAPPING["新部门"] = "标准部门"
```

## 🎯 最佳实践

### 对于最终用户

1. **尽量使用标准列名**（参考模板）
2. **部门名称使用标准名称**或在 DEPT_MAPPING 中配置别名
3. **日期格式统一**为 YYYY-MM-DD 或 YYYY/MM/DD
4. **数值不要包含符号**（如 ¥、$）

### 对于管理员

1. **定期更新 COLUMN_MAPPING**，收集用户反馈的新别名
2. **维护 DEPT_MAPPING**，确保所有部门都有映射
3. **提供转换脚本**给用户，用于预处理特殊格式的文件
4. **监控导入错误**，发现新模式后及时更新映射表

## 📝 常见问题

### Q1: 我的 Excel 列名不在映射表中怎么办？
A: 有两种方式：
1. 临时：使用转换脚本手动指定映射
2. 永久：联系管理员添加到 COLUMN_MAPPING

### Q2: 部门名称映射不准确怎么办？
A: 检查 DEPT_MAPPING 是否包含该部门，如果没有，可以：
1. 添加到 DEPT_MAPPING
2. 或使用标准部门名称

### Q3: 日期格式不支持怎么办？
A: 当前支持：
- YYYY-MM-DD
- YYYY/MM/DD
- YYYY年MM月DD日
- Excel 日期序列号

如需支持其他格式，请联系管理员扩展 `convert_date_format()` 函数。

### Q4: 如何处理大量不同格式的文件？
A: 建议：
1. 创建标准的导入模板供用户使用
2. 提供转换脚本作为预处理工具
3. 建立常见的列名别名库
4. 定期收集用户反馈，更新映射表
