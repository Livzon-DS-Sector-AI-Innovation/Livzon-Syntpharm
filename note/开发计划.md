# 仿制药原料药研发系统 - 开发计划

**更新日期**: 2026-08-28  
**版本**: v1.0

---

## 一、总体策略

### 核心原则
1. **聚焦核心研发流程** - 先补齐小试、中试、开题等关键缺失
2. **暂缓申报和验证** - 保留接口，后续再实现
3. **数据完整性优先** - 所有功能必须符合ALCOA+原则
4. **分阶段实施** - 快速迭代，每2周一个里程碑

### 开发优先级
- 🔴 **P0**: 现场核查必查项（起始物料、小试验证、中试管理）
- 🟡 **P1**: 效率和质量保障（文档自动化、预算管理）
- 🟢 **P2**: 协同和智能化（任务协作、风险评估）

## 二、Phase 1：核心研发流程补全（第1-8周）

### 1.1 立项与开题增强模块（第1-2周）

#### 数据库模型
```python
class ProjectInitiation(Base):
    """项目立项与开题"""
    id: UUID
    project_id: UUID
    
    # 调研报告
    market_research: Text
    patent_analysis: Text
    sales_data: JSON
    
    # 立项报告
    development_strategy: Text
    target_product_profile: JSON  # QTPP
    
    # 开题报告（QbD核心）
    synthetic_route: Text
    starting_materials: JSON
    cqas: JSON  # 关键质量属性
    cpps: JSON  # 关键工艺参数
    
    # 研究计划与预算
    gantt_chart: JSON
    material_budget: JSON
    labor_budget: JSON
    total_cost_estimate: Decimal
    
    status: str
```

#### API端点
- `POST /api/research/initiations` - 创建立项开题
- `GET /api/research/initiations/{id}` - 获取详情
- `PUT /api/research/initiations/{id}` - 更新
- `POST /api/research/initiations/{id}/approve` - 审批

#### 前端页面
- `ProjectInitiationPage` - 统一的立项开题表单
- `GanttChartView` - 可视化研究计划
- `BudgetCalculator` - 预算自动计算
