# 04 — 前端数据透视舱界面适配

**What to build:** 实现具有工业美感的“数据透视舱”界面，通过色彩编码和状态徽章直观展示导入逻辑。支持用户在预览阶段修改数据并实时校验位号冲突。

**Blocked by:** 03 — 导入 API 端点整合 (/preview & /batch)

**Status:** ready-for-agent

- [ ] 实现预览表格的视觉编码：蓝色高亮财务字段，灰色表示业务字段
- [ ] 添加匹配策略徽章（复合/位号/模糊）和重复行跳过标记
- [ ] 实现设备位号的实时唯一性校验与冲突提示
- [ ] 开发导入结果展示组件，包含批次 ID 和审计日志入口
- [ ] 确保界面在大量数据下的渲染性能与响应速度
